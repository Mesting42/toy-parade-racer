# 三端适配与浏览器验收

本轮从 2026-10-20 开始，2026-10-21 完成。用户明确选择手机按键式操作：左侧转向，右侧加速、漂移和道具。沿用六种精致合金玩具赛车与原有手工赛道视觉。

## 手机方向判断

比赛优先横屏，菜单兼容竖屏。追车镜头下，横屏更便于预判弯道、看到相邻赛车，并使双手操作区远离中央路线。竖屏保留可玩退路，不把整个网页强制旋转。

竖屏开赛会先暂停倒计时，显示横屏准备与继续竖屏两个入口。全屏/方向锁定只在用户点击时请求，不支持的浏览器可手动旋转。手机比赛中旋转会清除持续按键并暂停，保留圈数、赛车与计时；用户点击继续后恢复。

## 改动与直接修复的问题

- `src/display.js` 统一屏幕判断、自动画质和追车镜头参数。手机横竖屏保持流畅档；起跑镜头按真实车头方向定位，修复初始镜头朝向树木后再慢慢转回赛道的问题。
- `src/responsive.css` 为电脑、平板、手机竖屏和短横屏适配 HUD、菜单、设置、车库与驾驶区域；触控按钮至少 44×44，遵循安全区。
- 增加触屏「复位」，多指加速/转向/漂移维持独立指针状态；取消、释放、失焦和暂停时清除输入。输入框/选择框内的方向键、空格不触发驾驶。
- 平板首页第三个车型曾被挤出屏幕，已改为三按钮完整排布；最终第三个按钮右边界约 740.41，小于 768px。
- 手机首页全屏与操作说明曾位于顶栏后，已移入首页滚动内容，并实际点击打开说明验证。
- 320px 车库标题曾被三列挤成竖排；已去除重复余额并重排标题。设置滑杆与数值改成稳定的两行排布。
- 320×568 短竖屏道具说明曾覆盖车尾，已压缩为图标、类别与名称；横屏保持用途说明。
- 1024×768、鼠标指针环境曾只显示未定位/未装饰的触控按钮；已将完整样式统一绑定至 `.touch-ui`，不依赖浏览器是否报告粗指针。
- 弹层背景设置 inert，并将焦点放到弹层按钮，避免暂停或横屏准备时操作背后的驾驶控件。
- 预览服务曾缓存旧样式；已重启并为 Windows 配置文件轮询，最终浏览器加载了最新修改。

## 浏览器覆盖

在应用内浏览器操作正常游戏菜单和比赛，使用真实页面按钮及键盘；DOM 只读取布局和显示值，没有注入比赛状态。尺寸调整属于浏览器视口模拟，不代表实际设备或移动浏览器内核。

| 场景 | 尺寸 | 检查 |
| --- | --- | --- |
| 桌面 | 1440×900 | 菜单、比赛、键盘 W 加速、暂停/继续、隐藏触控区 |
| 平板竖屏 | 768×1024 | 三车型完整显示、选赛道、比赛 HUD、触控区 |
| 平板横屏 | 1024×768 | 完整触控样式、复位与暂停、驾驶区与 HUD 分离 |
| 手机竖屏 | 390×844 | 首页、选赛道、横屏引导、继续竖屏、旋转暂停 |
| 手机横屏 | 844×390 | 按住加速实际提速、复位、暂停清理、触控区域边界 |
| 短横屏 | 800×360 | HUD 与触控区不重叠、按钮至少 44×44 |
| 小尺寸竖屏 | 320×568 | 车库、设置、游戏 HUD、道具栏压缩、操作按钮边界 |

手机横屏实际持续按下加速后，HUD 车速升至约 93 km/h；释放后 pressed 类数量为 0。点击触屏复位后出现「回到赛道，短暂护航中」。旋转暂停的两次计时读数均为 `00:31.306`，确认没有继续计时。桌面 W 加速实测约 57 km/h。

最终记录的按钮均在视口内，触控目标至少 44×44；速度/漂移区与方向键、道具栏与踏板区没有交叠，页面无横向溢出。`layout-measurements.json` 保留了修复前 1024×768 按钮尺寸异常，以及对应的最后通过记录。最后浏览器警告/错误日志为空，视口恢复正常尺寸，返回主菜单。
