# 火箭追踪与六车不同模型修复

日期：2026-10-19（Asia/Shanghai）。

## 问题复现与修改

用户反馈火箭只向前飞，未真正攻击前车。旧 `advanceRocket()` 始终推进赛道坐标，横向速度固定；前车很近但在另一车道时，火箭会先越过目标的赛道位置。此时取模距离变成接近整圈，火箭继续绕赛道而没有直接追上车身。

先添加“前车只领先 6，双方在 -9 / +9 车道”的回归，旧逻辑实际失败。修改后：远距离沿赛道追赶，近距离切换为持续锁定车身的三维追踪，使用扫掠检测命中，支持移动、变道和跳起的目标；已锁定目标冲线后结束飞行。长距离火箭寿命按与目标的追赶速度计算，首位无目标空射仍在 3.5 秒后消失。

用户明确选择“6 名选手各用一种不同车型”。从本地保留的 Kenney Toy Car Kit 原包追加 `vehicle-drag-racer`、`vehicle-vintage-racer`、`vehicle-suv` 到运行资源。玩家仍可选择原三款车，电脑使用其余五种不同车身；更换玩家车型后重新分配，快速比赛和锦标赛均覆盖。三款新车都有四个独立车轮，涂装使用实际车身 UV 对应图集区域；结果页增加新车型名称。

## 实际验证

- `npm test`：43 项通过，0 失败。近距离跨车道问题回归已由失败转为通过；移动目标测试在九条赛道各覆盖近、中、远三种距离（27 种情况），包含左右变道和跳起，全部在火箭寿命内命中；另测目标冲线后飞行结束。
- 三种玩家车型、快速比赛与锦标赛的六车模型均不重复；读取六款真实 GLB 核对四轮、无人物、尺寸、涂装 UV、本地纹理与许可。
- `npm run build`：成功，23 modules，主包约 723.9 kB / gzip 200.5 kB；保留大于 500 kB 的体积提示。
- 三款新增 GLB 的开发服务请求全部 HTTP 200。
- 本轮应用内受控浏览器恢复可用。在独立演示页实际点选“近距离跨车道追击”，观察火箭命中栗子队长、车身升空翻转；暂停检查帧显示翻滚约 116°、速度 0 m/s。已保存实际浏览器截图 `验收截图/2026-10-19/rocket-hit-roll.jpg`。
- 在同一演示页点选“六车车型对照”，实际看到六种不同车身。截图 `验收截图/2026-10-19/six-distinct-cars.jpg`。
- 从正常首页进入快速比赛、点击驶入赛道、键盘 W 加速，HUD 达到 84 km/h，随后正常暂停、离开并回到菜单。该页面及演示页读取的浏览器警告/错误日志均为空。

演示页主动布置车辆和供应道具，自动驾驶并可在命中时暂停；截图说明的是实际渲染与相同战斗代码的运行，不是正常随机拾取的人工比赛或完整九站锦标赛验收。没有清除存档。
