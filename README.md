# 《玩具巡游赛》

一款单人、明亮手作布景风格的浏览器卡丁车游戏。路线、物理、道具、主题地标、音效和配乐由项目本地代码生成；无人物完整车壳的玩具赛车、门架、模块路肩、跳坡、模型树与看台载入本地 Kenney GLB 模型。运行时不加载 CDN 或远程素材。

## 环境与启动

- Node.js 20 或更新版本
- npm 10 或更新版本

Windows 可以双击 `启动游戏.bat`。首次运行会安装依赖；之后由 Vite 启动本地网页服务器，并在终端显示访问地址。

命令行操作：

```powershell
npm install
npm run dev
```

开发服务器启动后，在浏览器打开 Vite 输出的本地地址。

## 构建与验证

```powershell
npm test
npm run build
npm run preview
```

`npm test` 会检查九条赛道的闭合投影与三圈自动驾驶、六车开赛与冲线冻结、七类道具效果、拾取库存和护罩防御，也会回归锦标赛三杯九站的推进、低分重赛、积分解锁、存档续赛和最终排名结算。火箭回归覆盖按名次锁定、跨终点追踪、电脑拾取后主动攻击、护罩拦截、受击翻滚和停速。

## 模式

- **快速比赛**：选择已开放赛道和电脑难度，与五名电脑车手跑三圈。
- **锦标赛**：三杯共九站，第一杯累计 9 分开放第二杯；前两杯累计 18 分开放第三杯。每站按名次获得 10、7、5、3、2、1 分，累计成绩保存在本机。
- **计时挑战**：单人跑三圈，记录最快圈和本机幽灵车。
- **自由练习**：没有电脑对手和终点压力，可熟悉路线、跳板与漂移。

比赛约两到四分钟；单次锦标赛会跨九站累计成绩，完成后展示冠军纪念页。练习和计时可单独打开已解锁赛道。

## 操作

| 动作 | 键盘 | 常见手柄 | 触屏 |
| --- | --- | --- | --- |
| 加速 | `W` / `↑` | `A` 或右扳机 | 右侧「加速」 |
| 刹车 | `S` / `↓` | `B` 或左扳机 | 右侧「刹车」 |
| 左右转向 | `A` / `D` 或方向键 | 左摇杆 | 左侧方向按钮 |
| 漂移蓄力 | 转向并按住 `Shift`，出弯松开 | `LB` | 「漂移」 |
| 使用道具 | `Space` | `X` | 「道具」 |
| 快速复位 | `R` | — | 右上「复位」 |
| 暂停/继续 | `Esc` | `Start` | 右上暂停键 |

触屏支持多指同时按住。手机以横屏比赛为主：左侧转向，右侧加速、刹车、漂移和道具；菜单适合竖屏浏览。手机竖屏进入比赛时先显示横屏准备提示并暂停倒计时，也可选择「继续竖屏游玩」。比赛中切换手机方向会暂停并清除持续按键，点击继续后保留原圈数和进度。支持的浏览器可通过「横屏 / 全屏准备」进入全屏并请求横屏；不支持锁定方向时可直接手动旋转手机。

电脑、平板与手机共用完整比赛流程。触屏按钮最小 44×44，短横屏压缩 HUD 并保留中央驾驶视野，短竖屏的道具栏仅显示图标、类别与名称。自动画质按手机短边判断，手机横竖屏均保持流畅档，避免旋转后突然提高渲染负担。

三端浏览器检查与截图见 `.impeccable/review/responsive-2026-10-21.md` 和 `验收截图/2026-10-20/`。这是浏览器尺寸与交互检查，未替代实体手机和平板的硬件性能测试。

## 随机道具与可见效果

问号箱只从游戏已实现的七种道具中随机抽取。每个名次都有机会获得全部种类，名次只轻微影响概率。玩家和电脑使用同一套效果与命中规则。

| 道具 | 效果 |
| --- | --- |
| 弹簧推进器 | 推进 2 秒；尾部双喷口显示蓝色根焰、亮芯和橙色火焰，带烟尾与火星；漂移推进也会喷火。 |
| 泡泡护罩 | 可见的蓝青色能量外壳持续 4.5 秒，抵挡一次碰撞或攻击；拦截后显示护盾扩散环。 |
| 追踪火箭 | 发射时锁定当前前一名；远处沿赛道追赶，近处直接追踪车身并命中，支持跨车道和跳起目标。第二名攻击第一名、第三名攻击第二名。第一名向前发射，飞行后消失。 |
| 黏胶团 | 在身后留下可见胶滩，减慢驶过的对手。 |
| 弹簧震荡波 | 向周围扩散冲击环，在约 0.48 秒内将附近未受保护的对手向外推开约一个车身，并短暂减速；实体障碍仍会阻挡位移。 |
| 纸盒诱饵 | 在身后留下带红色警示标记的假道具箱，撞上会减速。 |
| 磁力吸附器 | 显示紫色磁场环，吸附附近齿轮币，最长持续 5.2 秒。 |

未受保护的车被火箭命中后会升空并翻滚一整圈；翻滚期间不能驾驶或使用道具，落地时速度为零，随后重新加速。护罩与受击保护可阻止连续击飞。电脑会根据前方目标、附近对手和道路情况释放手中的道具。

开发服务器提供独立的[道具效果演示页](http://127.0.0.1:5175/.impeccable/review/item-effects-preview.html)。该页面使用游戏相同的模型、物理和特效，主动布置演示场景并自动驾驶，不读取或写入存档；不作为正常比赛或锦标赛的人工跑通证据。

## 进度与设置

存档使用浏览器 `localStorage`，仅保存在当前设备，包含杯赛成绩、齿轮币、选中车辆与涂装、设置、计时记录和幽灵车。六种涂装以比赛获得的齿轮币解锁，不提供付费优势。无法读取存档时会以新档启动；在「赛道设置」中可调整画质、特效、音乐、音效、转向灵敏度、镜头震动、粒子与闪光。清空进度需要再次确认。

玩家三款赛车来自本地 Kenney Toy Car Kit：黄蜂冲锋使用 `vehicle-racer-low`，蘑菇慢邮使用 `vehicle-racer`，松果铁皮使用 `vehicle-speedster`。比赛另外加入流星长尾 `vehicle-drag-racer`、复古银箭 `vehicle-vintage-racer`、薄荷越野 `vehicle-suv`。每场由玩家先选车型，再将其余五种不同模型分配给电脑，因此六名选手车身均不重复；更换玩家车型后重新分配。

六种均为完整车壳、无人物模型；四轮分别滚动、前轮随转向摆动。合金玩具车细化包含圆滑橡胶轮胎、胎纹、各车型不同辐数的金属轮毂与螺栓、前灯和分段尾灯、格栅、深色玻璃、窗框、雨刷、门把手、车身接缝与号码涂装；赛车增加进气口和散热槽。细节按照实际车身表面装配，车漆使用清漆与本地生成的环境反射，玩家、电脑、车库与幽灵车共用装配流程。CC0 许可与原始包均已保留。

开发服务器另提供[合金车模型细节页](http://127.0.0.1:5175/.impeccable/review/car-detail-preview.html)，可切换六款车型的前侧、后侧、轮毂近景和六车合影。该页使用游戏相同模型与光照，不读写游戏存档。
